# Intelligent-Log-Analytics-and-Failure-Diagnosis-system
Built an AI-powered log analytics system that automatically ingests and analyzes system logs detecting failures and anomalies
with 91% detection accuracy.
Implemented XGBoost-based failure classifier combined with LLM-powered root cause explanation generating human-readable
diagnosis reports for each detected incident.
Engineered an automated fix recommendation engine mapping detected failure patterns to resolutions, reducing Mean Time to
Resolution (MTTR) by 45%
